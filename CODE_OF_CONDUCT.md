# Code of Conduct

MoonDocKit aims to be a practical, welcoming MoonBit ecosystem project.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent when reviewing issues or pull requests.
- Keep discussions focused on reproducible behavior, design tradeoffs, and
  project goals.
- Credit external ideas, examples, and source projects when they inform a
  contribution.

## Unacceptable Behavior

- Harassment, insults, or personal attacks.
- Publishing private information without permission.
- Submitting code or generated content without a clear license or source.
- Repeatedly ignoring maintainer guidance about project scope or safety.

## Scope

This code of conduct applies to repository issues, pull requests, review
threads, documentation, examples, and project communication related to
MoonDocKit.

## Enforcement

Maintainers may edit, close, or remove comments and contributions that violate
this code of conduct. Serious or repeated violations may result in being
blocked from further participation in the project.

For the competition baseline, enforcement is handled by the repository owner.
If MoonDocKit grows into a broader community package, this document should be
updated with dedicated maintainer contact information.
