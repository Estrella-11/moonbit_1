Quick Start

MoonDocKit turns MoonBit package notes into a small static documentation site.

  • parse front matter
  • render HTML pages
  • generate navigation
  • build a search index

Install

Add the package once it is published to mooncakes.io.

Generate

Use the library API to build an output manifest, then write every OutputFile

to a destination directory. See the MoonBit website

for language documentation.
