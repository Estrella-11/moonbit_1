# Overview

This is a starter documentation site generated by **MoonDocKit**. Replace these
files with your own Markdown and run one command to publish a static site.

MoonDocKit gives you:

- A navigable multi-page site with a reading-progress bar
- In-page full-text search (`search-index.json` + a zero-dependency script)
- A light/dark theme toggle persisted in `localStorage`
- A publishing quality gate (empty pages, missing titles, duplicate routes all fail the build)

## What to edit

1. Drop your `.md` files into this `site/` directory.
2. Each page starts with front-matter that controls order and tags:

   ```markdown
   ---
   order: 1
   tags: [guide]
   ---

   # Your title
   ```

3. Update `moondockit.json` (title, `site_url`, description, theme).
