# Overview

SampleStatKit is a small MoonBit statistics package used to demonstrate
MoonDocKit adoption outside the main repository documentation.

The package author keeps three ordinary inputs:

- handwritten usage notes
- release notes
- a generated `.mbti` interface

MoonDocKit turns those files into a browsable documentation site with search,
navigation, API reference output, and a machine-readable site manifest.

## Why This Case Matters

This example proves the workflow is not tied to MoonDocKit's own source pages.
The same CLI can document a separate package shape with its own title,
metadata, routes, and API symbols.
