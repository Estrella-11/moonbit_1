# Support

Use this guide to choose the right support path for MoonDocKit.

## Questions

For usage questions, start with:

- `README.md`
- `docs/configuration.md`
- `docs/adoption-playbook.md`
- `docs/feature-evidence-map.md`
- `docs/windows-toolchain-troubleshooting.md`

If the answer is not covered, open a GitHub or Gitlink issue with:

- what you are trying to build;
- your MoonBit version;
- the command you ran;
- the relevant Markdown, config, or `.mbti` snippet.

## Bugs

Use the bug report issue template. Include a minimal reproduction and whether
the failure happens in:

- the MoonBit library;
- the JavaScript-targeted CLI;
- generated HTML output;
- generated API reference output;
- local toolchain setup.

If `moon.exe` is blocked by Windows Device Guard or organization policy, follow
`docs/windows-toolchain-troubleshooting.md` before reporting it as a project
bug.

## Feature Requests

Use the feature request template and explain the MoonBit package documentation
workflow it improves. Features that help package authors publish, review, or
maintain docs are more likely to fit the project scope.

## Security Reports

For suspected rendering or output-safety issues, see `SECURITY.md`.
